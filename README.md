# FMD — Télécharger le logiciel

**[⬇ Télécharger FMD pour Windows](https://github.com/YCN-png/fmd-telechargement/releases/latest/download/FMD-Setup.exe)**

1. Ouvrez le fichier `FMD-Setup.exe`. Si Windows affiche « Windows a protégé votre ordinateur » :
   **Informations complémentaires** → **Exécuter quand même** (le logiciel n'est pas encore signé).
2. Suivez l'installation : un raccourci **FMD** est créé sur le Bureau.
3. Connectez-vous avec votre compte FMD : vos projets et données sont en ligne, rien à copier.

Le logiciel se met à jour tout seul à chaque ouverture.
